# Contract: Feed Post Paging

## Purpose

Define the paging behavior for all feed post lists generated by the query engine.

## Page Types

Initial page:

- Input: query spec without cursor.
- Output: first `pageSize` posts for the active filter and sort shape.
- Cursor: next cursor is derived from the last returned item when a full page is returned.

Append page:

- Input: query spec with cursor from the same filter and sort shape.
- Output: next posts strictly after the cursor.
- Cursor: next cursor is derived from the last returned item when a full page is returned.

Refresh-around page:

- Input: query spec with anchor cursor from the same filter and sort shape.
- Output: page centered around or starting at the anchor according to the paging source behavior.
- Cursor: next cursor is derived from the last returned item when a full page is returned.

## Cursor Rules

- Cursor contains the sort identity and one value per sort term.
- Cursor values are ordered exactly like the active sort terms.
- Cursor values use stored sort keys, not display values when those differ.
- Append comparisons are exclusive so the cursor row does not repeat.
- Refresh-around comparisons may include the anchor row.
- Cursor is invalid if filters or sort change.

## Stability Invariants

- No offset or page-number pagination is allowed for feed post lists.
- Each supported sort ends in unique post identity.
- A full ordered result set and the concatenation of cursor-loaded pages must contain the same post IDs in the same order.
- Duplicate posts are not allowed across appended pages.
- Skipped posts are not allowed unless they no longer match the active filters at refresh time.
- New or updated posts may invalidate the paging source, but refresh must keep the user near the anchor item.

## Invalidation Scope

Paging sources must track changes to:

- Feed posts.
- Feeds.
- Post-tag mappings.
- Post tags.
- Post categories.

## Required Acceptance Coverage

- Initial page for every supported sort.
- Append page for every supported sort.
- Refresh around anchor for representative long, text, boolean-first, and feed-derived sorts.
- Missing published time, missing title, and missing feed name.
- Positive and negative boolean media filters.
- Cursor rejection when sort identity or value shape does not match.
